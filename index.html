A glossary of design systems for AI, user interfaces and user experience.

78 entries

A

Accessibility
People with different abilities can perceive, understand and operate a product. A disclosure control needs a readable label, keyboard operation and an expanded state that assistive technology can announce.
Accessible name
The name assistive technology uses to identify a control. An icon-only search button can have the accessible name “Search”.
Adoption
The extent to which teams use a system in shipped work. Count the checkout screens using the shared field as well as the teams that installed it.
Affordance
An action a user can take with an interface. A resizable panel affords changing its width. A visible grip helps people discover that action.
AI disclosure
An indication that AI generated or changed something. Label a generated summary where people read it, and keep the label attached when the summary is expanded.
Alignment
Placing elements along a shared edge, axis or baseline. Aligning prices by the decimal makes a column of amounts easier to compare.
Anatomy
The named parts of a component. A text field can include a label, input, hint and error message, each with a distinct job.

B

Baseline grid
A set of horizontal guides for the baselines of type. Captions and body text can share a rhythm even when set at different sizes.
Breakpoint
A threshold at which a layout changes arrangement. Switch a split view to a stack when its reading column becomes too narrow.

C

Citation
A reference connecting a generated claim to its source. Place the link beside the claim and open the relevant passage so the reader can check it.
Cognitive load
The mental effort a task demands. Keeping shipping options and their prices together saves the reader from remembering one while comparing the other.
Component
A reusable interface element with defined structure and behavior. A shared checkbox handles its label, hit area, checked state and keyboard interaction together.
Composition
Combining smaller parts into a larger whole. A search field and a results list can form a picker while retaining their individual responsibilities.
Consistency
Using familiar conventions for recurring situations. Keep the action for saving a draft in a predictable place across editors.
Constraint
A limit that guides input or layout. A date picker can disable dates before the start of a reservation and explain which dates are available.
Content design
Choosing and structuring information around what someone needs to do. A payment error should say what happened and how to continue.
Context window
The amount of input and output a model can handle in one request. In a long conversation, show which files or earlier messages will be included when the user sends the next turn.
Contrast
A perceptible difference between elements. Lightness, size and weight can each distinguish a heading from the text beneath it.
Contribution model
The path for proposing, reviewing and maintaining a change. A team proposing a date picker brings examples of the tasks the existing controls cannot support.
Conversational repair
A way to recover when an assistant misunderstands a request. Let someone correct a destination while keeping the travel dates already established.

D

Density
The amount of content and spacing within an area. A compact data table can expose more rows while preserving legible labels and usable controls.
Deprecation
Retiring a supported feature in stages. Name its replacement and give teams a migration path before removing the old component.
Design principle
A shared rule of judgment that helps resolve trade-offs. “Preserve the reader’s place” guides what should happen after a list refreshes.
Design system
The shared decisions, resources and practices that help teams build a coherent family of products. It includes the people and processes that keep those resources usable.
Design token
A named design decision expressed as data. A spacing token can carry the same intended gap from a design file into several codebases.
Discoverability
How readily someone can find an available action. A visible formatting toolbar makes choices easier to discover than a gesture alone.

E

Empty state
The interface shown when there is nothing to display. A new inbox and a search with zero matches call for different explanations.
Error prevention
Designing a flow to head off predictable mistakes. Show the recipient and amount together before a transfer is confirmed.

F

Feedback
A perceptible response to an action. Showing a file in the upload queue immediately confirms that dropping it worked.
Focus order
The sequence in which keyboard focus moves through interactive elements. A form should move from the field to its related actions in a meaningful order.
Foundation
A shared decision that many components rely on, such as a type scale, spacing unit or motion convention.

G

Governance
How a system assigns responsibility for decisions and maintenance. Specify who resolves conflicting proposals and who supports an accepted change.
Grid
A framework of lines, columns and gaps that relates elements across a layout. The same column boundaries can align a photograph, a title and a caption.
Grounding
Basing a generated response on relevant source material. A support assistant can use the current returns policy and link to the passage behind its answer.

H

Hit area
The region that accepts pointer or touch input. A small icon can sit inside a larger interactive area without growing its artwork.
Human review
A step where a person checks an AI result before it takes effect. Show the proposed edits and let the reviewer accept, change or discard them.

I

Inclusive design
A practice that involves people with varied abilities and circumstances in design decisions. Test a checkout with people who navigate by voice as well as by touch.
Information architecture
The organization and labeling of information so people can find their way. Group account settings according to the tasks people come to complete.
Inline suggestion
A proposed edit shown at the point of use. Keep suggested text visually distinct from accepted text and provide a keyboard action to dismiss it.
Interoperability
The ability of components or tools to work together through shared conventions. A token file can supply the same color roles to web and mobile libraries.

K

Keyboard navigation
Operating an interface through keys. A menu needs a predictable way to enter it, move between choices and leave it.

L

Leading
The distance between successive baselines of text. Adjust it alongside line length so readers can find the start of the next line.
Localization
Adapting a product to a language and region. A date field may need a different order, numeral system and example for each locale.

M

Mapping
The relationship between a control and its effect. In a two-pane editor, place each zoom control beside the preview it changes.
Model feedback
A way for people to report how well an AI response served their task. Attach feedback to the specific answer so later revisions retain their own feedback history.
Modularity
Organizing an interface into parts with clear responsibilities. A chat composer can swap its attachment picker while keeping its send and cancel controls.
Motion
Change over time that communicates relationships or status. An expanding panel can show where new content belongs in the existing layout.

N

Navigation
The structures that let people move between places. A section label and a current-page indicator answer different questions about location.

O

Optical alignment
Adjusting placement to account for perceived shape or weight. A play triangle often needs a slight shift to look centered inside a circle.

P

Pattern
A reusable approach to a recurring problem. Address entry is a pattern that combines several fields, validation and recovery.
Primitive token
A named base value that other tokens can reference. A palette step such as blue-600 can supply color to several roles.
Progressive disclosure
Revealing additional choices as they become relevant. A print dialog can show paper size first and expose color profiles on demand.
Prompt
The instruction or input given to a model. A writing assistant can pair a free-text field with an editable example that shows how to specify tone and audience.
Proximity
The tendency to read nearby elements as a group. Keep a caption closer to its image than to the next image.

Q

Quality assurance
Checking that an implementation meets its intended behavior. Exercise a selector with long labels, a keyboard, an empty list and a narrow screen.

R

Recognition over recall
Presenting cues people can recognize instead of requiring them to remember information. Recent destinations make a route picker easier to use.
Reduced motion
An experience that respects a preference for less movement. Replace a large animated zoom with an immediate transition that preserves orientation.
Regeneration
Requesting another output for an existing prompt. Keep the original draft available so the user can compare versions and recover earlier wording.
Responsive design
Letting content and layout adapt to available space. A gallery can change its column count while preserving a useful minimum image size.
Reversibility
Making it possible to undo a decision. An undo action after archiving supports quick work and easy recovery.

S

Semantic token
A named design value that describes a role. A text-on-accent token can select different colors in each theme while preserving its purpose.
Signifier
A cue that suggests how to act. An underline signals a link, while a grip beside a list item suggests that it can be reordered.
Spacing scale
A set of recurring distances for arranging elements. Smaller steps can bind a label to its field while larger steps distinguish groups.
State
A condition that changes a component’s appearance or behavior. A submit button may enter a pending state while a request is in flight.
Streaming response
An answer displayed incrementally as it is generated. Provide a stop control and let someone scroll back to an earlier passage without being pulled to the newest text.
Suggested prompt
A ready-made starting point for an AI interaction. On a document page, offer “Summarize this document” only when the assistant can access that document.

T

Theming
Changing a coordinated set of design values for a context. A dark theme can remap surface, text and border roles together.
Typography
The selection and arrangement of type for reading. Family, size, line length, spacing and weight work together to distinguish roles.

U

Uncertainty communication
Showing where an AI answer is incomplete or tentative. If two sources give different dates, surface the disagreement and link to each source.
Usability
How effectively, efficiently and satisfactorily people can complete a task in context. Observe someone recovering a draft to evaluate the whole flow.
User control
Giving people agency over actions and timing. A pause control lets a reader finish a rotating announcement at their own pace.
User intent
The outcome someone wants from an interaction. When “clean this up” could mean formatting or rewriting, let the user choose before applying changes.

V

Variant
A supported configuration of a component. A compact field can share the standard field’s behavior while using a different spacing treatment.
Visual hierarchy
The relative prominence of elements in a composition. A prominent invoice total can lead the eye before line items supply detail.

W

Wayfinding
Cues that help people understand where they are and where they can go. A breadcrumb shows a page’s place in the site, and a selected tab identifies the current view.
Whitespace
Unoccupied space that separates or connects the parts of a composition. A generous margin can make a short note easier to locate on a crowded page.

X

X-height
The height of lowercase letters such as x, excluding ascenders and descenders. Two typefaces at the same nominal size can feel quite different in a dense table.

Z

Z-index
A CSS property that sets stacking order within a stacking context. Define the relationship between a menu and a modal so each appears on the intended layer.
